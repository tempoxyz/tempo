# TIP-1116: T12 Hardfork Meta TIP

## Abstract

This meta TIP collects changes proposed for the T12 hardfork and links their
implementations. It relaxes trailing-byte validation in precompile ABI decoding
while retaining the other strict decoding checks introduced at T11, and aligns
native-precompile storage writes and static-call failures with EVM rules.

## Motivation

A shared T12 tracking document makes the proposed upgrade scope and implementation
dependencies reviewable. Allowing trailing ABI bytes restores compatibility for
otherwise valid precompile calls that include a suffix, without removing the
remaining decoding checks described in [TIP-1105](./tip-1105.md).
Native precompiles also need explicit enforcement of the EVM's storage-write gas
stipend check and static execution restrictions. Grouping these fixes here makes
their T12 activation and caller-visible changes explicit.

# Changes

## 1. Allow trailing ABI bytes in precompile calls

**PRs**: [#7598](https://github.com/tempoxyz/tempo/pull/7598) · **Author**: @klkvr

From T12, Tempo precompile dispatchers enable Alloy's
`validate_allow_trailing_bytes` option alongside the strict ABI validation enabled
at T11. Otherwise valid ABI arguments may be followed by unused trailing bytes;
strict validation of the decoded arguments remains enabled, including rejection
of gaps and truncation. The existing 16 MiB decoder memory limit remains in place.

Pre-T12 behavior is unchanged: T11 retains strict decoding without trailing-byte
acceptance, and earlier hardforks retain their historical decoding behavior.

## 2. Enforce the EIP-2200 stipend check for precompile storage writes

**PRs**: [#7647](https://github.com/tempoxyz/tempo/pull/7647) · **Author**: @0xrusowsky

From T12, the shared native-precompile `SSTORE` path checks the frame's remaining
gas against the configured call stipend, as required by
[EIP-2200](https://eips.ethereum.org/EIPS/eip-2200). If the remaining gas is less
than or equal to the stipend, the call frame halts with an out-of-gas error before
SSTORE gas charging or storage mutation. This check also applies to storage
increments and decrements (`sinc` and `sdec`) that use the shared write path.

Pre-T12 storage writes retain their historical behavior. At T12 and later,
callers must provide enough gas to satisfy both the stipend check and the
existing storage-write charges.

## 3. Halt mutating precompile calls during static execution

**PRs**: [#7643](https://github.com/tempoxyz/tempo/pull/7643) · **Author**: @0xrusowsky

From T12, the precompile dispatcher rejects mutating calls in a static context
with a frame-local exceptional halt, consistent with
[EIP-214](https://eips.ethereum.org/EIPS/eip-214). Before T12, dispatch retains the `StaticCallNotAllowed()` ABI revert.
