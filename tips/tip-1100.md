# TIP-1100: Increase Precompile Input Gas Cost

## Abstract

This TIP increases the input charge for every Tempo precompile from 6 to 30 gas
per 32-byte word at T11. The charge continues to apply to the complete calldata
before function dispatch or argument decoding.

## Motivation

The existing charge underprices some dynamic input decoding. Benchmarks measured
worst-case RLP decoding at approximately 300 MGas/s under the 6 gas-per-word
schedule, while large string inputs reached approximately 470–910 MGas/s.

Charging 30 gas per word raises the measured worst-case RLP rate to approximately
1.5 GGas/s. Applying one schedule to all precompiles also avoids relying on
post-decode charges, which do not protect decoding when a caller deliberately
under-forwards gas.

## Assumptions

- Input decoding cost grows linearly with calldata length.
- Every Tempo precompile charges for its complete calldata before decoding it.
- The additional cost is negligible for normal calls, which contain only a few
  calldata words.

## Threat Model

An untrusted contract may repeatedly call a precompile with large or malformed
calldata while reusing EVM memory. The input charge must therefore cover internal
calls independently of transaction calldata pricing and later execution costs.

---

# Specification

For every Tempo precompile call, let:

```text
words = ceil(calldata_length / 32)
```

The implementation MUST deduct the following execution gas before function
dispatch or argument decoding:

```text
before T11: words * 6
T11 onward: words * 30
```

The charge applies to all Tempo precompiles and all input bytes, including the
function selector. If the caller has insufficient gas, execution MUST halt with
out-of-gas before decoding. T11 does not change any other precompile gas charge.

# Tooling

N/A. Existing gas estimation observes the active hardfork's execution result and
no ABI or SDK interface changes.

# Observability

N/A. Existing transaction receipts and execution traces expose gas usage and
out-of-gas failures.

# Invariants

1. Pre-T11 execution continues to charge 6 gas per input word.
2. T11 and later execution charges 30 gas per input word.
3. Every Tempo precompile charges the complete calldata before decoding it.
